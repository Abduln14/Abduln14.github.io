Car Price Prediction

PythonXGBoostScikit-learnPandasSQLStreamlit

Problem

Used-car buyers and sellers have no clear way to judge whether a price is fair.

Approach

Trained XGBoost on 10,000+ records. Added buyer and seller modes, confidence ranges, EMI and depreciation calculators, a budget-based recommender and a car health score built from age, mileage and ownership.

Fridge Hero

PythonGoogle Gemini APIRAGChromaDBSentence-TransformersFlaskSQLiteStreamlit

Problem

Food gets thrown away because nobody tracks what is about to expire.

Approach

Flask and SQLite backend for live inventory, expiry alerts and restocking suggestions. Gemini parses natural-language input and recommends 3 recipes that use near-expiry items first. A RAG pipeline (ChromaDB with local Sentence-Transformers embeddings) answers food-safety questions from USDA FoodKeeper data, and a chat assistant uses tool calling.

Result

A conversational app for non-technical users, built at zero cost with Gemini's free tier, response caching and rule-based fallbacks, exposing 7 API endpoints.
